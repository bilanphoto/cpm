โปรแกรมวางแผนงานหยุดซ่อมบำรุงโรงงานด้วย Critical Path Method (CPM)

1. ข้อมูลโครงการ

กำหนดหน่วยเวลาของแต่ละกิจกรรมได้แยกกัน ระบบจะแปลงทุกกิจกรรมเป็นนาทีภายในก่อนคำนวณ CPM

2. รายการกิจกรรม

งานก่อนหน้าใช้รหัสกิจกรรม คั่นด้วย comma เช่น T01,T02 ความสัมพันธ์ที่รองรับคือ Finish-to-Start (FS)

ES = เริ่มเร็วที่สุด, EF = เสร็จเร็วที่สุด, LS = เริ่มช้าที่สุด, LF = เสร็จช้าที่สุด, Float = ระยะเวลาสำรอง

4. แผนภาพเครือข่าย CPM (AON)

แผนภาพ Activity-on-Node แสดงรหัสงาน ระยะเวลา ES/EF/LS/LF/Float ลูกศรแสดง dependency และสีแดงแสดงกิจกรรมวิกฤต คลิกกล่องเพื่อเลือกกิจกรรม

เพิ่มกิจกรรมเพื่อสร้างแผนภาพ

หลักการคำนวณ

  • ใช้ CPM แบบ Activity-on-Node (AON) และ Finish-to-Start (FS)
  • Forward pass: ES = ค่าสูงสุดของ EF จากงานก่อนหน้า; EF = ES + Duration
  • Backward pass: LF = ค่าน้อยสุดของ LS จากงานถัดไป; LS = LF − Duration
  • Total Float = LS − ES; กิจกรรมที่ Float = 0 ถือเป็น Critical
  • นาทีเป็นหน่วยมาตรฐานภายใน; 1 ชั่วโมง = 60 นาที, 1 วัน = 24 ชั่วโมง, 1 สัปดาห์ = 7 วัน
  • การแสดงวันทำงานเป็นเพียงการประมาณวันที่ ไม่ได้เปลี่ยนตรรกะ CPM และยังไม่รองรับกะทำงานหรือวันหยุดนักขัตฤกษ์
  • ก่อนใช้จริงให้ตรวจสอบ logic, resource constraints, isolation, permit, SIMOPS, QA/QC และ commissioning
